What happens during training?

  1. Data Cleaning — Missing values handled, rows with unknown country dropped
  2. One-Hot Encoding — rate_type column encoded into binary columns
  3. MinMax Scaling — Numeric columns normalised to [0, 1]
  4. Target Creation — good_match = 1 if rating ≥ 4/5 AND reviews > 0
  5. 80/20 Split — Stratified train/test split
  6. 3 Models — Random Forest, Logistic Regression, Neural Network (MLP)
  7. Evaluation — Accuracy, F1-Score, Precision, Recall per class

Which model should I use?

  • Random Forest — Best overall accuracy. Robust, handles non-linear patterns. Recommended default.
  • Logistic Regression — Fast and interpretable. Good baseline for linearly separable data.
  • Neural Network (MLP) — Learns complex patterns. May need more data to outperform RF.

Interpreting the PCA Plot

PCA reduces the 5+ numeric features into 2 dimensions while preserving maximum variance. Overlapping clusters suggest the classes are not linearly separable in this 2D projection — which is why non-linear models like Random Forest and Neural Networks tend to outperform Logistic Regression on this dataset.
