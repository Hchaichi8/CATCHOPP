How does it work?

  1. Content Extraction — Combines job_title + tags + rate_type + client_country into a text field
  2. TF-IDF Vectorisation — Converts text into a 500-feature numeric matrix
  3. Cosine Similarity — Measures angle between your skill vector and each project vector
  4. Ranking — Returns top N projects sorted by similarity score
